> [!TIP]
> ## 1️⃣ تحلیل مسئله
> کاربر یک عدد وارد می‌کند.  
> 
> - اگر طول عدد خیلی زیاد باشد → احتمالاً **ترابایت** است.  
> - اگر کم باشد → احتمالاً **بایت** یا **کیلوبایت** است.  
> - ما بر اساس **تعداد رقم‌ها** تشخیص می‌دهیم که واحد چیست.  
>
> #### 📏 فرض تبدیل‌ها:
> - `1 KB = 1024 Bytes`  
> - `1 MB = 1024 KB`  
> - `1 GB = 1024 MB`  
> - `1 TB = 1024 GB`  
>
> ## 2️⃣ منطق تصمیم‌گیری
> - **1 تا 3 رقم** → Bytes  
> - **4 تا 6 رقم** → KB  
> - **7 تا 9 رقم** → MB  
> - **10 تا 12 رقم** → GB  
> - **بیشتر از 12 رقم** → TB

## 🎲 Game 1: Number Guessing

🔹 The computer selects a **random number** between 1 and 10.
🔹 The player guesses until they find the correct number.
🔹 The program shows how many attempts were made.

**Concepts:** `while loop`, `if-else`, `random`, user input.

---

## 🎲 Game 2: Multiplication Table

🔹 The player enters a number.
🔹 The program prints the multiplication table (1 → 10).

**Concepts:** `for loop`, user input, string formatting.

---

## 🎲 Game 3: Countdown

🔹 The player enters a number.
🔹 The program counts down to 0.
🔹 Prints **Boom!** at the end.

**Concepts:** `for loop` with negative step.

---

## 🎲 Game 4: Secret Word Guessing

## Game 4: Secret Word Guessing

```python
import random

WORDS = ["python", "variable", "function", "operator", "loop", "package"]
secret = random.choice(WORDS)
guessed = set()
tries = 0
max_tries = 8

print("کلمه مخفی را حدس بزن! (فقط حروف انگلیسی)")

while tries < max_tries:
    masked = "".join(ch if ch in guessed else "_" for ch in secret)
    print(f"کلمه: {masked}    (فرصت باقیمانده: {max_tries - tries})")
    letter = input("یک حرف: ").strip().lower()
    if len(letter) != 1 or not letter.isalpha():
        print("فقط یک حرف معتبر وارد کن.")
        continue
    if letter in guessed:
        print("این حرف را قبلاً گفته‌ای.")
        continue
    guessed.add(letter)
    if all(ch in guessed for ch in secret):
        print(f"آفرین! کلمه '{secret}' بود.")
        break
    if letter not in secret:
        tries += 1
        print("نادرست.")
else:
    print(f"باختی! کلمه '{secret}' بود.")
```
